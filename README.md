# sharrwah-countries-context

Context research on the countries and merchants Sharrwah may serve: how money moves, how goods are delivered, how people buy and sell, and the conditions around them. Yemen is the first country here. Other countries in the Middle East and North Africa may follow.

## Why it is kept apart

Sharrwah's reference model and architecture are worked out elsewhere. This repository holds only what is known about each country. A country's requirements inform how Sharrwah is set up there. They never redefine what the product is.

## Layout

One folder per country under `countries/`, each with its own `README.md` that indexes its files.

```
countries/
  yemen/
```

## How to read it

- **Provenance.** Each file opens with a short note: where it came from (repository, commit and path), when it was written, and whether it is copied whole or is an excerpt.
- **Sources and dates.** Facts carry their sources and dates as they appear in the original. Statements the original marks as weaker (search-result summaries, unverified listings, anecdotes) keep those marks.
- **Age.** Research written before 3 November 2026 is earlier research. It has not been reviewed since and should be re-verified before it is used.
